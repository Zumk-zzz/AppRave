# AppRave

Мобильное приложение ночного клуба: билеты, бронирование столиков, предзаказ на баре
и клубная карта. Одна кодовая база на iOS и Android.

## Стек

Expo SDK 54 (React Native 0.81, React 19.1) · TypeScript · expo-router v6 · Reanimated 4 · Zustand

## Запуск

```bash
npm install
```

```bash
npx expo start
```

### Проверка на iPhone

Mac не нужен. Установите **Expo Go** из App Store, подключите телефон к той же сети,
что и компьютер, откройте Камеру и наведите на QR-код из терминала.

Если телефон и компьютер в разных подсетях (например, ПК по кабелю, а телефон в гостевом
Wi-Fi), запустите с туннелем:

```bash
npx expo start --tunnel
```

Правки подхватываются на лету — пересканировать QR не нужно.

> **SDK не апгрейдить.** Expo Go в App Store поддерживает только SDK 54; версии для
> SDK 55–57 висят в ревью Apple. Переход на новую SDK потребует Apple Developer Program
> ($99/год) и сборки dev build через EAS.

## Структура

```
app/          экраны и навигация (expo-router, файловый роутинг)
src/theme/    дизайн-токены: цвета, отступы, типографика
src/          компоненты, сервисы данных, сторы, мок-данные
assets/       иконки и изображения
```

Данные пока моковые и живут за слоем `src/services/*` — экраны обращаются только туда,
поэтому подключение реального бэкенда не потребует переписывать интерфейс.
