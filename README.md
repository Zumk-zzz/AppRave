# AppRave

Мобильное приложение ночного клуба: билеты, бронирование столиков, предзаказ на баре
и клубная карта. Одна кодовая база на iOS и Android.

## Стек

Expo SDK 54 (React Native 0.81, React 19.1) · TypeScript · expo-router v6 · Reanimated 4 · Zustand

## Запуск

```bash
npm install
```

```bash
npx expo start
```

### Проверка на iPhone

Mac не нужен. Установите **Expo Go** из App Store, подключите телефон к той же сети,
что и компьютер, откройте Камеру и наведите на QR-код из терминала.

Если телефон и компьютер в разных подсетях (например, ПК по кабелю, а телефон в гостевом
Wi-Fi), запустите с туннелем:

```bash
npx expo start --tunnel
```

Правки подхватываются на лету — пересканировать QR не нужно.

> **SDK не апгрейдить.** Expo Go в App Store поддерживает только SDK 54; версии для
> SDK 55–57 висят в ревью Apple. Переход на новую SDK потребует Apple Developer Program
> ($99/год) и сборки dev build через EAS.

## Возможности

- **Вход по номеру телефона** с кодом из SMS, сессия сохраняется между запусками
- **Афиша** — лента вечеринок с фильтром по жанрам, лайнап, типы билетов
- **Столики** — визуальная схема зала, депозит, гостевой список
- **Бар** — предзаказ напитков к приходу, 19 позиций по категориям
- **Единый заказ** — билеты, стол и бар в одной корзине, один QR на вечеринку
- **Клубная карта** — уровни Silver / Gold / Black, баллы, привилегии
- **Админка** — афиша, меню бара, склад с журналом движений, столы, заказы

### Вход администратором

Номер `+7 900 000-00-00`, код тот же `0000`. Раздел администрирования появится
в профиле. Обычный гость его не видит, и маршруты `admin/*` для него закрыты
на уровне роутера, а не только спрятаны в интерфейсе.

## Структура

```
app/          экраны и навигация (expo-router, файловый роутинг)
  (auth)/     вход: приветствие, телефон, код
  (tabs)/     афиша, столики, бар, карта, профиль
  event/      карточка вечеринки
  ticket/     билет с QR
src/
  theme/      дизайн-токены: цвета, отступы, типографика
  components/ UI-кит: Button, Card, Chip, Sheet, Stepper, Text
  features/   экранные блоки: схема зала, карточки событий, панель заказа
  services/   доступ к данным: интерфейсы + мок-реализации
  store/      состояние: сессия, корзина, заказы
  data/       мок-данные: афиша, меню бара, схема зала
  lib/        форматирование цен и дат, склонения, логика уровней
```

Экраны обращаются к данным **только** через `src/services/*`. Сейчас там моки; чтобы
подключить бэкенд, достаточно заменить реализации в [src/services/index.ts](src/services/index.ts) —
интерфейс тот же, экраны не меняются.

## Что пока не настоящее

- **Оплата** — мок с задержкой в полторы секунды. Настоящий эквайринг требует нативного
  SDK, недоступного в Expo Go.
- **Код из SMS** — всегда `0000`.
- **Данные** — моковые, живут в `src/data/`.

Билеты, бронь стола и напитки — реальные товары и услуги, поэтому правила App Store
(3.1.3/3.1.5) не только разрешают, но и **требуют** использовать обычный эквайринг
вместо In-App Purchase. Комиссии Apple 30% на них не будет.

## Проверки

```bash
npx tsc --noEmit && npx expo-doctor
```

Типов недостаточно: Metro не видит новые папки из кэша, поэтому после добавления
директорий в `src/` сборку нужно проверять запросом бандла, а не только `tsc`.
Подробности в [AGENTS.md](AGENTS.md).
