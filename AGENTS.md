# AppRave — заметки для агентов

## Жёсткие ограничения

- **SDK строго 54.** Не апгрейдить. Expo Go в App Store (54.0.2) поддерживает только SDK 54 —
  сборки для 55/56/57 застряли в ревью Apple. Апгрейд SDK = приложение перестанет
  открываться на телефоне разработчика, у которого Windows и нет Mac.
- **Только модули, работающие в Expo Go.** Никаких библиотек, требующих своей нативной
  сборки (настоящий Stripe SDK, Apple Pay и т. п.) — до перехода на dev build.
- Разработка идёт на Windows: нет Xcode, нет iOS-симулятора. Проверка только через Expo Go.

## Конвенции

- Язык интерфейса — **русский**, валюта — **рубли**.
- Цвета, отступы и шрифты берутся **только** из `src/theme` — hex-значений в компонентах быть не должно.
- UI не ходит за данными напрямую, только через `src/services/*`. Рядом с моками
  лежит реализация на бэкенде; какая из них работает, решает `extra.dataSource`
  в `app.json`, и экраны об этом не знают.
- **Заказ меняется только через `ordersService`.** Покупка, отмена, возврат на
  склад и выдача — одна операция сервиса, а не несколько шагов в экране: на
  сервере за ней стоит транзакция, и повторять её на телефоне нельзя. Копии
  разойдутся, и склад перестанет сходиться с продажами.
- **Сторы в `src/store` — кэш, а не хранилище.** Данные лежат в сервисе (в базе
  или в `*.mock.ts`), стор держит то, что уже показано, и после правки
  перечитывает. Сервис, который читает из стора, куда сам же и пишет, разрезать
  при подключении сервера придётся по живому — так уже было с каталогом.
- **Возврат денег защищён не одним подтверждением, а четырьмя условиями:**
  право `payments:refund` (только админ), вечеринка уже переведена
  в «Отменена», точное название в подтверждении, и всё это перепроверяется
  на сервере. Ослаблять любое из них нельзя: это единственное действие,
  которое двигает деньги обратно, и цена случайного нажатия — реальные
  деньги и доверие гостей.
- **Журнал действий пишет только тот, кто исполняет действие.** Экран в журнал
  не пишет: в режиме сервера запись делает сам сервер в одной операции с
  выдачей. Журнал, в который можно дописать что угодно, ничего не доказывает,
  а нужен он именно для разбирательств с недостачей.
- Алиас путей: `@/*` → корень проекта (`@/src/theme`, `@/src/components`).
- Оплата на текущем этапе — **мок**. В интерфейсе это должно быть явно обозначено.

## Грабли

- **Новая папка в `src/` → Metro её не увидит.** `tsc` проходит, а бандл падает с
  `Unable to resolve "@/src/..."`. Лечится перезапуском с `npx expo start --clear`.
  Проверять сборку нужно запросом бандла, а не только через `tsc`:
  `http://<lan-ip>:8081/.expo/.virtual-metro-entry.bundle?platform=ios&dev=true&transform.routerRoot=app`
  (путь `/index.bundle` в expo-router отдаёт 404).
